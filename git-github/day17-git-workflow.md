# Day 17 - Git Add, Commit, Push & Pull

## Commands Practiced

### Check Status

```bash
git status
```

### Stage Changes

```bash
git add .
```

### Commit Changes

```bash
git commit -m "message"
```

### Push Changes

```bash
git push origin main
```

### Pull Changes

```bash
git pull origin main
```

## Key Learnings

- git add stages files
- git commit creates a snapshot
- git push uploads changes to GitHub
- git pull downloads latest changes from GitHub
