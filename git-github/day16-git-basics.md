# Day 16 - Git Basics

## What is Git?

Git is a distributed version control system used to track changes in files and source code.

## What is GitHub?

GitHub is a cloud platform used to host Git repositories.

## Commands Practiced

### Check Git Version

```bash
git --version
```

### Check Repository Status

```bash
git status
```

### View Remote Repository

```bash
git remote -v
```

### View Commit History

```bash
git log --oneline
```

## Key Learnings

- Git tracks file changes.
- GitHub hosts repositories online.
- git status shows repository state.
- git log shows commit history.
