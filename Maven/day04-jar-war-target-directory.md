# 🚀 Maven Day 4 - JAR, WAR, Target Directory & Artifact Generation

## Objective

Learn how Maven generates build artifacts, understand JAR vs WAR packaging, and see how Maven integrates with Jenkins pipelines.

---

# What is an Artifact?

An artifact is the final output produced by a Maven build.

Examples:

```text
portfolio-service-1.0.0.jar
portfolio-service-1.0.0.war
```

Common artifact types:

- JAR
- WAR

---

# What is JAR?

JAR = Java Archive

Contains:

- Compiled Java Classes
- Configuration Files
- Libraries
- Metadata

Example:

```text
portfolio-service-1.0.0.jar
```

Typically used for:

- Spring Boot Applications
- Microservices

---

# Portfolio Management Platform Example

Services:

```text
portfolio-service.jar
trade-service.jar
client-service.jar
risk-engine.jar
```

Each microservice is packaged independently.

---

# What is WAR?

WAR = Web Archive

Used for:

- Traditional Web Applications
- Applications deployed on Tomcat, JBoss, WebLogic, WebSphere

Example:

```text
portfolio-portal.war
```

Contains:

- JSP
- Servlets
- HTML
- CSS
- JavaScript
- WEB-INF

---

# JAR vs WAR

| JAR | WAR |
|------|------|
| Java Archive | Web Archive |
| Microservices | Web Applications |
| Spring Boot | Traditional Applications |
| Self-contained | Requires Application Server |

# Target Directory

Very Important Interview Topic.

When Maven builds a project:

```bash
mvn package
```

it creates:

```text
target/
```

Example:

```text
target/
├── classes/
├── generated-sources/
├── maven-status/
└── portfolio-service-1.0.0.jar
```

---

# Purpose of Target Directory

Stores:

- Compiled Classes
- Generated Files
- Reports
- Final Artifact

Think of it as:

```text
Build Output Directory
```

---

# Maven Package Command

Command:

```bash
mvn package
```

Lifecycle executed:

```text
validate
↓
compile
↓
test
↓
package
```

Output:

```text
target/
└── portfolio-service-1.0.0.jar
```

---

# Maven Clean Package

Most common CI/CD command.

```bash
mvn clean package
```

Process:

```text
Delete old target/
        ↓
Compile
        ↓
Run Tests
        ↓
Create JAR
```

---

# Why mvn clean package?

Without clean:

```text
Old build files may remain.
```

With clean:

```text
Fresh build every time.
```

Recommended in:

- Jenkins
- GitHub Actions
- Azure DevOps
- GitLab CI

---
