# Client Service

## Overview

Client Service manages investor and customer information.

## Responsibilities

- Create Client
- Update Client Profile
- Manage KYC Information
- Relationship Management

## API Endpoints

### Create Client

```http
POST /api/v1/client
```

### Update Client

```http
PUT /api/v1/client/{clientId}
```

### Get Client

```http
GET /api/v1/client/{clientId}
```

## Database

- Oracle RDS
